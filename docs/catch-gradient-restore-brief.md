# Panda Factory トップページ追加修正 指示書
## PC版キャッチ背景グラデーションの復活・全幅化

## 今回の修正目的

前回の修正で、PC版のキャッチコピー周辺にあった黒グラデーションが消えてしまいました。

今回やりたいことは、**グラデーションを消すことではなく、以前あったキャッチ背景グラデーションを復活させたうえで、画面端までフル幅に広げること**です。

---

## 1. PC版ではキャッチ背景グラデーションを必ず復活させる

対象キャッチ：

```text
A SMALL WORKSHOP. A WORLD OF IDEAS.
つくる。動かす。ちょっと便利にする。
```

PC版では、このキャッチコピーの背面に黒系グラデーションを必ず表示してください。

### 重要

- グラデーションレイヤー自体を削除しない
- `display: none` にしない
- PCサイズで非表示にしない
- 単なるベタ黒背景に置き換えない

今回の意図は、

```text
KV
↓
徐々に暗くなる
↓
キャッチコピー
↓
自然に下の黒背景へ接続
```

という見え方です。

---

## 2. グラデーションは画面端までフル幅にする

以前の状態では、キャッチ周辺だけに局所的な暗部がありました。

今回はそのグラデーションを、ヘッダーと同じように**画面左端から右端まで届く全幅表示**にしてください。

### 方向性

```text
画面上部
ヘッダーの黒グラデーション

        KV

キャッチ背景の黒グラデーション
画面下部
```

上下でKVを自然に挟み込む構成にします。

---

## 3. 推奨実装

HeroやKVに `max-width` が設定されていても、グラデーションはViewport全幅にしてください。

例：

```css
.hero-catch-gradient {
  position: absolute;
  left: 50%;
  bottom: 0;

  width: 100vw;
  height: 220px;

  transform: translateX(-50%);
  pointer-events: none;

  background: linear-gradient(
    to top,
    rgba(12, 9, 11, 0.95) 0%,
    rgba(12, 9, 11, 0.72) 35%,
    rgba(12, 9, 11, 0.28) 70%,
    rgba(12, 9, 11, 0) 100%
  );
}
```

数値は固定ではありません。実画面を見ながら調整してください。

---

## 4. キャッチコピーとCTAはグラデーションより前面に出す

以下の要素はグラデーションより前面に表示してください。

- キャッチコピー
- `EXPLORE PROJECTS`

例：

```css
.hero-catch-gradient {
  z-index: 1;
}

.hero-copy,
.hero-cta {
  position: relative;
  z-index: 2;
}
```

`EXPLORE PROJECTS` の黄色が暗く濁らないようにしてください。

---

## 5. モバイルはPCと別制御にする

モバイルでキャッチ背景グラデーションを弱める、またはOFFにするのは問題ありません。

ただし、**その設定をPC版まで巻き込まないでください。**

例：

```css
@media (max-width: 768px) {
  .hero-catch-gradient {
    display: none;
  }
}
```

このような非表示処理を行う場合は、必ずモバイル用Media Query内に限定してください。

### 注意

以下のような全体適用は不可です。

```css
.hero-catch-gradient {
  display: none;
}
```

---

## 6. 今回変更しない部分

以下は現状維持でお願いします。

- 中央KVのサイズ
- KVの `contain` ベース表示
- 左右のBlur背景
- Blur背景のBrightness / Saturation
- ヘッダーのデザイン
- ヘッダーのスクロール挙動
- キャッチコピーの文言
- `EXPLORE PROJECTS` の基本デザイン
- KV画像そのもの

## 完成条件

### PC版

- キャッチ背景グラデーションが復活している
- グラデーションが画面左端から右端まで届いている
- KV下部から黒背景へ自然にフェードしている
- キャッチコピーが読みやすい
- `EXPLORE PROJECTS` の黄色が暗くなっていない
- 左右のBlur背景はそのまま維持されている

### モバイル版

- `EXPLORE PROJECTS` にグラデーションが被っていない
- モバイル専用の調整がPC版に影響していない

---

## 最重要ポイント

> **PC版のキャッチ背景グラデーションは消さないでください。**
>
> **以前あったグラデーションを復活させ、その横幅だけをViewport全幅へ広げる修正です。**
>
> **モバイルで非表示にする場合は、必ずMedia Query内だけで制御してください。**
