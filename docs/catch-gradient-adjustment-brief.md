# Panda Factory トップページ追加調整 指示書
## キャッチコピー背景グラデーション / モバイルCTA干渉修正

## 目的

前回の調整により、KV全体がファーストビュー内に収まり、左右のBlur背景も意図通りに機能しています。

今回の追加修正では、以下2点を整えてください。

1. PC版のキャッチコピー背景グラデーションを、ヘッダーと同じように**画面端までフル幅で表示**する
2. モバイル版でキャッチコピー用グラデーションが `EXPLORE PROJECTS` ボタンに被らないようにする

---

## 1. PC版：キャッチコピー背景を画面全幅にする

現在はキャッチコピー周辺だけが局所的に暗くなっており、グラデーションの終端が途中で見える状態です。

これを、ヘッダーの黒グラデーションと対応するように、**画面の左端から右端まで伸びる下側グラデーション**へ変更してください。

### 方向性

- 局所的なRadial Gradientではなく、下端から上へ自然に消えるLinear Gradientを基本としてください
- KVコンテナ幅ではなく、ブラウザのViewport全幅にしてください
- 黒い帯として見えないよう、上方向へ自然にフェードさせてください
- キャッチコピー自体の位置・文字デザインは変更しないでください

### 実装例

```css
.hero-catch-gradient {
  position: absolute;
  left: 50%;
  bottom: 0;
  width: 100vw;
  height: 220px;
  transform: translateX(-50%);
  pointer-events: none;

  background: linear-gradient(
    to top,
    rgba(12, 9, 11, 0.92) 0%,
    rgba(12, 9, 11, 0.68) 35%,
    rgba(12, 9, 11, 0.20) 70%,
    rgba(12, 9, 11, 0) 100%
  );
}
```

数値は固定ではありません。実画面を確認しながら調整してください。

### 重要

HeroやKV側に `max-width` が設定されていても、キャッチ用グラデーションはその幅に制限されず、必ずViewport端まで届くようにしてください。

```css
left: 50%;
width: 100vw;
transform: translateX(-50%);
```

のような構成で問題ありません。

## 2. PC版：上下のグラデーションを対になる見せ方にする

トップページ全体として、以下の構成を意識してください。

```text
画面上端
████████████████████████
▓▓▓▓▓▓▓▓▒▒▒▒░░          ← Header Gradient

            KV

          ░░▒▒▒▒▓▓▓▓▓▓▓▓
████████████████████████  ← Catch Gradient
画面下端
```

狙いは、ヘッダー側とキャッチコピー側の暗部でKVを自然に挟み込み、中央のKVを主役として見せることです。

---

## 3. モバイル版：キャッチ用グラデーションをCTAに被せない

現在のモバイル表示では、キャッチコピー用グラデーションが下方向へ伸びすぎており、`EXPLORE PROJECTS` ボタンに被っています。

これにより、黄色いCTAが暗く濁って見えるため修正してください。

### 必須条件

- `EXPLORE PROJECTS` ボタンにはキャッチ用グラデーションを一切被せない
- CTAの黄色は常に本来の色を維持する
- キャッチコピーとCTAの視覚的な領域を分離する
- キャッチ用オーバーレイの `z-index` や高さを見直し、CTA領域へ侵入させない

---

## 4. モバイル版ではグラデーションをOFFにしてもよい

モバイル表示では、KV画像の下にキャッチコピーが配置され、その背景自体がすでに黒系になっています。

そのため、モバイルではPCと同じ大きなグラデーションを無理に使用する必要はありません。

最もシンプルで自然であれば、モバイル時はキャッチ用グラデーションを無効化して構いません。

### 例

```css
@media (max-width: 768px) {
  .hero-catch-gradient {
    display: none;
  }
}
```

または、どうしても残す場合はキャッチコピー周辺だけに限定し、CTAへ届かない高さにしてください。

```css
@media (max-width: 768px) {
  .hero-catch-gradient {
    height: 100px;
  }
}
```

モバイルでは「グラデーションを残すこと」よりも、**キャッチコピーとCTAが明確に分離されていること**を優先してください。

---

## 5. 今回変更しない部分

以下は現在の状態が良いため、基本的に変更しないでください。

- 中央KVのサイズ
- KVの `contain` ベースの表示
- 左右のBlur背景
- Blur背景のBrightness / Saturationの方向性
- ヘッダーの現在の見た目
- スクロール後のヘッダー挙動
- キャッチコピーの文言
- `EXPLORE PROJECTS` の位置・デザイン
- KV画像そのもの

特に、左右のBlur背景は現在の状態を維持してください。

---

## 完成条件

### PC

- キャッチコピー側の黒グラデーションが画面左端から右端まで途切れず伸びている
- ヘッダーの上側グラデーションと自然に対になる
- 黒い長方形や途中で切れた暗部に見えない
- 中央KVが引き続き主役に見える
- キャッチコピーの可読性が確保されている

### モバイル

- キャッチコピー用グラデーションが `EXPLORE PROJECTS` に被っていない
- `EXPLORE PROJECTS` の黄色が暗く濁っていない
- キャッチコピーとCTAが視覚的に分離されている
- 必要であればモバイル時はキャッチ用グラデーションをOFFにする

---

## 最重要ポイント

> **PCではキャッチコピー背景を「局所的な暗部」ではなく、画面全幅の下側グラデーションにする。**
>
> **モバイルでは、そのグラデーションをCTA領域へ絶対に侵入させない。**
>
> **左右のBlur背景と中央KVの現在の状態は維持する。**
